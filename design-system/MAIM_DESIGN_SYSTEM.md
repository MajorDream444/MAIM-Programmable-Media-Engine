# MAIM Design System

Status: **Canonical foundation — extend deliberately**

This file translates the existing MAIM brand structure into machine-readable production rules for designers, developers, and media agents. It does not replace the original MAIM 00 source project; it provides the canonical implementation layer for the Programmable Media Engine.

## 1. Brand Position

MAIM is a human-centered intelligence and transformation system. It should feel like a global movement shaped by Afro-Caribbean heritage, New York championship energy, earned wisdom, education, community, and premium editorial craft.

Technology must feel natural and useful. Avoid generic robot imagery, neon cyberpunk skins, dashboard clichés, and decorative AI spectacle.

## 2. Core Doctrine

- AI is the Intelligence. You are the Wisdom.
- See it. Believe it. Build it.
- Likkle by likkle, we build the future.
- Humans are the hero.
- One life. One archive. Infinite expressions.

## 3. Visual Language

### Foundation
- Black foundation
- Gold authority
- Jamaican green accents
- Champion blue highlights
- Warm ivory for human readability
- Green · gold · blue tri-bar as a recurring navigation and emphasis device

Exact production HEX, RGB, CMYK, and accessibility pairs must be extracted from approved MAIM source assets before a release is marked final. Agents must not invent permanent token values when source values are unavailable.

### Typography
- **Archivo** — primary display, headline, title, and strong instructional typography
- **JetBrains Mono** — metadata, technical labels, timestamps, system language, manifests, and restrained interface accents
- Maximum 4–5 words in high-impact thumbnail and short-form headlines when possible
- No paragraphs inside motion title cards
- Resolve important marks and words with sufficient hold time

### Marks
- Crown coin seal — trust mark
- Major Dream signature / MD watermark — founder authenticity mark
- MAIM wordmark — primary brand identity
- Tri-bar — continuity, rhythm, and system progression

Do not distort, redraw, recolor, or approximate official marks when approved source assets exist.

## 4. Composition Rules

- Premium editorial hierarchy
- Minimal typography
- One dominant idea per frame
- Real humans in frame whenever the narrative supports it
- Founder performance remains the narrative anchor in founder-led films
- Separate foreground subject, message layer, and atmospheric layer
- Use negative space intentionally
- Decorative particles and glow may never compete with the human face or primary message

## 5. Motion Language

Motion should communicate transformation, progression, connection, memory, and earned authority.

Preferred families:
- documentary push-ins
- premium title and word reveals
- sequential foundation-word progressions
- network and connection metaphors
- text-to-system transformations
- restrained depth and parallax
- closing brand signatures

Rules:
- one primary motion idea per shot
- avoid repeating the same hero technique within one sequence
- reserve frames for breathing room
- synchronize major transitions and impacts to musical structure
- use generative footage only when a needed human or environmental shot cannot be sourced conventionally

## 6. Human Imaging

- Warm cinematic lighting
- Rich Afro-Caribbean color tones
- Authentic skin texture
- Calm, confident teacher energy
- Emotional close-ups and purposeful environmental context
- Diverse generations and cultures where the narrative is collective
- No dystopian AI imagery
- No gratuitous futuristic interfaces

## 7. Safe Areas and Readability

Every production must define its master format and derivative crops before final composition.

Required checks:
- 16:9 master
- 1:1 square
- 9:16 vertical
- caption collision
- face and eye-line protection
- logo protection
- platform UI obstruction zones

Existing locked vertical guidance:
- top clear zone: 18%
- bottom clear zone: 22%

YouTube banner guidance:
- protect centered 1546 × 423 safe area inside 2560 × 1440 canvas

## 8. Audio Character

- Human, soulful, confident, forward-moving
- Afrobeat-pop and light reggae bounce are valid when appropriate
- Sound design should support motion rather than announce every movement
- Prefer restrained riser → impact → tail phrases
- Maintain cue sheets and provenance for all licensed audio

## 9. Agent Rules

Every agent creating MAIM media must:

1. Read this file before proposing a visual direction.
2. Inspect approved MAIM assets before assigning permanent color or logo values.
3. Preserve human performance as the primary authority layer.
4. Cite the source of every third-party asset.
5. Produce safe-area and still-frame QA outputs.
6. Store reusable techniques in the library and production-specific decisions in the production folder.
7. Never overwrite upstream toolkits with MAIM production assets.

## 10. Claude Design Briefing Rule

Claude Design may extend the MAIM system, but every exploration must begin from this foundation and return:

- design rationale
- token additions or changes
- component inventory
- usage rules
- prohibited uses
- responsive/safe-area variants
- export inventory
- provenance and source references

No exploration becomes canonical until reviewed and committed to this repository.
