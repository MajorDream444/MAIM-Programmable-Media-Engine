# MAIM Programmable Media Engine

**Record once. Create forever.**

The MAIM Programmable Media Engine turns raw human experience into structured, searchable, adaptable, and monetizable media IP.

## System Layers

1. **Brand Intelligence** — canonical MAIM design tokens, doctrine, typography, safe areas, motion and audio rules.
2. **Agent Skills** — reusable instructions for ingest, story extraction, design, editing, QA, publishing, and provenance.
3. **Media Library** — reusable components, shot recipes, title systems, captions, transitions, diagrams, sound cues, and brand signatures.
4. **Production Runtime** — deterministic Remotion and FFmpeg workflows, with generative tools used selectively for source footage.
5. **Media Vault** — source masters, transcripts, derivatives, manifests, rights, and analytics.
6. **Operations Layer** — Airtable production registry, Notion architecture and decisions, Google Drive working assets, and GitHub canonical source.

## Canonical Tool Roles

| Platform | Role |
|---|---|
| GitHub | Canonical architecture, code, skills, manifests, schemas, and QA automation |
| Notion | Product doctrine, design decisions, production briefs, approvals, and human-readable operating system |
| Airtable | Structured asset, production, skill, rights, and release registry |
| Google Drive | Working media, brand assets, large source files, review exports, and delivery packages |
| Claude Design | Visual exploration and MAIM design-system extension |
| Remotion | Deterministic composition, typography, timing, captions, diagrams, and final assembly |
| Higgsfield | Selective generated B-roll only when conventional production cannot provide the shot |
